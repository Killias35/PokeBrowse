# 🧢 PokéBrowse (Chrome Extension)

Une extension Chrome qui transforme la navigation web en une expérience de capture et de collection de créatures inspirées de l’univers des jeux de collection.

---

## 📦 Installation

- Télécharger le dépôt.
- Ouvrir Chrome et accéder aux extensions : ``chrome://extensions``
- Activer le **mode développeur**.
- Cliquer sur **“Charger l’extension non empaquetée”**.
- Sélectionner le dossier du projet.

---

## 🎮 Jeu

- Ouvrir l’extension et faire apparaître un Pokémon via le bouton principal, ou activer le mode chasse.
- Les Pokémon apparaissent aléatoirement (environ un toutes les 5 minutes).
- Lorsqu’un Pokémon apparaît, cliquer dessus pour tenter de le capturer.
- La liste des Pokémon pouvant apparaître est accessible via le bouton **Hautes Herbes**, situé dans le coin supérieur gauche.
- Les paramètres (son, nom, description et image) sont accessibles via le bouton **Paramètres**, situé dans le coin supérieur droit.
- Le classement (leaderboard) est accessible via le bouton **Classement**.

---

## ⚙️ Fonctionnalités

- Liste des Pokémon disponibles.
- Mode chasse actif.
- Système de capture.
- Personnalisation des paramètres.
- Classement des joueurs.

---

## ⚠️ Particularités

- Certains Pokémon n’apparaissent que sur des sites spécifiques.
- Les Pokémon shiny existent, leurs chances d'apparaitrent augmente avec le nombre de pokemons apparaissent sur la même page.
- Un classement est dédié aux joueurs ayant capturé le plus de shinies.
