# 🧢 PokéBrowse (Extension Chrome)

Une extension Chrome qui transforme la navigation web en une expérience de capture et de collection de créatures inspirées de l'univers des jeux de collection.

---

## 📦 Installation

1. Téléchargez le dépôt.
2. Ouvrez Chrome et accédez à la page des extensions : `chrome://extensions`
3. Activez le **mode développeur**.
4. Cliquez sur **« Charger l'extension non empaquetée »**.
5. Sélectionnez le dossier du projet.

---

## 🚀 Initialisation

1. Ouvrez le Pokédex grâce au bouton de l'extension et laissez les données se télécharger.
2. Une fois les données prêtes, créez un compte avec un pseudo unique et un mot de passe. Cela permettra de sauvegarder votre progression et de la synchroniser entre différentes machines.
3. Tout est prêt, vous pouvez commencer à jouer.

---

## 🎮 Comment jouer

- Ouvrez l'extension et faites apparaître un Pokémon grâce au bouton principal, ou activez le mode chasse et attendez leurs apparitions.
- Les Pokémon apparaissent aléatoirement (environ un par minute).
- Lorsqu'un Pokémon apparaît, cliquez dessus pour tenter de le capturer.
- La liste des Pokémon pouvant apparaître est accessible via le bouton **Hautes Herbes**, situé dans le coin supérieur gauche.
- Les paramètres (son, nom, description et image) sont accessibles via le bouton **Paramètres**, situé dans le coin supérieur droit.
- Le classement (leaderboard) est accessible via le bouton **Classement**, situé sous le bouton **Hautes Herbes**.
- La déconnexion se fait grâce au bouton **Déconnexion**, situé sous le bouton **Paramètres**.

---

## ⚙️ Fonctionnalités

- Liste des Pokémon disponibles selon le nom de domaine visité.
- Mode chasse.
- Système de capture.
- Personnalisation des paramètres.
- Classement des joueurs.
- Sauvegarde de la progression.
- Capture des Pokémon shiny avec des effets visuels spéciaux.
- Difficulté de capture augmentant selon la rareté du Pokémon.
- Pokémon légendaires uniques apparaissant sur des domaines spécifiques en lien avec leur nature.
